# OneFeed Server
*A reactive content feed abstraction server made with Spring Boot*<br>
See also: [OneFeed](https://github.com/justinquinnb/OneFeed)

## About
Say goodbye to dated standards, clunky APIs, and bloated DTOs. OneFeed Server standardizes reading 
and writing content to feeds across platforms with a uniform, reactive REST API so your clients can 
focus on working with data, not platforms.

So long as your platform has a Provider written (or you can whip up a simple implementation), you
can read and write to any content feed your heart desires. Better yet, all data is normalized to
clean, modern schemas that make distribution, processing, and ingestion a breeze.

## Features
*All the benefits of [OneFeed](https://github.com/justinquinnb/OneFeed) plus...*
- **Unified REST API:** Read and write content with the same endpoints, no matter the feed or platform
- **Reactive-First:** All features offer reactive endpoints, minimizing the time-to-first-content/author load for clients
- **Standardized Model:** Present content across platforms with ease
- **Plugin Ecosystem:** Hot-swappable provider and cacher plugin support to reduce downtime and promote implementation reuse
- **Response Caching:** Reduce platform API calls and save your wallet by caching upstream platform data for later - *Coming Soon*
- **DTO Preservation:** Opt out of normalization to access API responses in their source DTOs
- **Centralized, Siloed Configuration:** Per-feed configurations in a single, centralized file with secret decoupling and siloing
